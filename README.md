# Long-runner ad rebuild (free Claude skill)

Find a competitor's longest-running Meta ad and rebuild its structure and hook for your brand: headline options, primary text, a visual brief and three sizes, ready to launch. Brands don't keep paying for ads that lose money, so long-running ads are the best free research there is.

**Install:** add the `long-runner-ad-rebuild` folder to your Claude skills (or upload the .skill file in Claude's Skills settings), then ask: "Find my competitors' longest-running ads and rebuild the best one for my brand."

**Works with:** Claude (claude.ai, Claude Code, Cowork). Best with a browser so it can read the Meta Ad Library directly; otherwise paste screenshots.

**License:** free to use for your own brand.
